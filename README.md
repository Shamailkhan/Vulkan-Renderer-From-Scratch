# Vulkan-Renderer-From-Scratch
A modern low-level renderer written entirely in C++ using the Vulkan API. This project explores how contemporary rendering engines manage GPU resources, synchronization, command submission, and real-time rendering without relying on third-party rendering frameworks.
The renderer is being developed as an educational and portfolio project to understand the architecture used in modern game engines and rendering pipelines.
# Features
  ## Rendering Architecture
  - Vulkan 1.3
  - GLFW Window System
  - Validation Layers
  - Vulkan Memory Allocator (VMA)
  - Dynamic Rendering
  - Render Graph (planned)
  - Multi-threaded Command Recording (planned)
## Core Vulkan Systems
  - Physical Device Selection
  - Logical Device Creation
  - Queue Family Management
  - Swapchain Creation
  - Image Views
  - Render Passes
  - Framebuffers
  - Synchronization Objects
  - Command Pools
  - Command Buffers
## GPU Resource Management
  - Buffers
  - Images
  - Image Layout Transitions 
  - Descriptor Pools
  - Descriptor Sets
  - Descriptor Set Layouts
  - Push Constants
  - Uniform Buffers
  - Storage Buffers
## Shader System
  - GLSL
  - SPIR-V Compilation
  - Vertex Shaders
  - Fragment Shaders
  - Compute Shaders

## Compute Pipeline

  - GPU Buffer Processing
  - Parallel Compute Dispatch
