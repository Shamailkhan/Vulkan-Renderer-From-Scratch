# Vulkan-Renderer-From-Scratch
A modern low-level renderer written entirely in C++ using the Vulkan API. This project explores how contemporary rendering engines manage GPU resources, synchronization, command submission, and real-time rendering without relying on third-party rendering frameworks.
The renderer is being developed as an educational and portfolio project to understand the architecture used in modern game engines and rendering pipelines.
##Features
#Rendering Architecture
Vulkan 1.3
GLFW Window System
Validation Layers
Vulkan Memory Allocator (VMA)
Dynamic Rendering
Render Graph (planned)
Multi-threaded Command Recording (planned)
